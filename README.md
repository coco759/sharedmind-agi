# sharedmind-agi

## 탁송 오더 매니저 (`index.html`)

카카오톡 오더 대화 내용을 붙여넣으면 출발지/도착지/연락처/차량/금액 등을 자동으로 추출하고,
거래처(의뢰인)에게 보낼 확인 문자와 기사에게 보낼 안내 문자를 한 번에 생성·복사할 수 있는
단일 HTML 앱입니다. 서버/빌드 없이 브라우저에서 `index.html`을 열거나 아무 정적 호스팅에
올려서 바로 사용할 수 있습니다.

### 주요 기능

- **오더 자동 추출**: 붙여넣은 카톡 텍스트에서 정규식 기반으로 전화번호, 차량번호, 차량명,
  주소, 금액(탁송료/주유비), 날짜, 요청사항을 뽑아 편집 가능한 폼에 채워줍니다. 자동 추출은
  참고용이며 생성 전에 검수/수정하도록 설계했습니다.
- **거래처별 도착지 프리셋**: 거래처마다 자주 쓰는 도착지 주소를 별칭(예: "유원지이글")으로
  저장해두면, 오더 텍스트에 그 별칭만 언급돼 있어도 저장된 전체 주소/연락처로 자동 치환됩니다.
  거래처/프리셋은 브라우저 `localStorage`에 저장됩니다.
- **문자 2종 자동 생성 + 복사**: "거래처(의뢰인)에게 보낼 확인 문자"와 "기사에게 보낼 안내
  문자"를 각각 생성하고 복사 버튼으로 바로 붙여넣을 수 있습니다.
- **노션 붙여넣기용 복사**: 오더/출발지/도착지/금액/주유비/날짜/차량/거래처 순서의 탭 구분
  텍스트를 복사해 노션 표에 바로 붙여넣을 수 있습니다.
